4. Ficheros de objetos (serialización)

Se guardan objetos enteros con ObjectOutputStream.writeObject() y se leen con ObjectInputStream.readObject(). La clase debe implements Serializable; si no → NotSerializableException (Pregunta 29).

Añadir objetos a un fichero existente → StreamCorruptedException (Pregunta 20)

Cada ObjectOutputStream escribe una cabecera al crearse. Si abres en modo añadir con un ObjectOutputStream normal, el fichero tiene varias cabeceras y al leer salta StreamCorruptedException.

Truco: "si existe → My + true; si no existe → normal". La versión invertida crea el fichero SIN cabecera.

5. XML con DOM

DOM carga todo el XML en memoria como un árbol de nodos (Document → Element → Text/atributos). Permite leer y crear/modificar.

7. XStream (objetos Java ⇄ XML)

XStream convierte un objeto en XML (toXML) y al revés (fromXML). Cada atributo de la clase genera un elemento hijo con su nombre; si el atributo es un objeto, sus campos se anidan dentro.

MétodoEfecto

addPermission(AnyTypePermission.ANY)Permiso para leer (fromXML); sin él → ForbiddenClassException
alias("etiqueta", Clase.class)Nombre de la etiqueta de una CLASE. Sin alias: nombre completo de la clase (paquete.Clase; en el paquete por defecto, "Producto")
addImplicitCollection(Clase.class, "atributo")Quita la etiqueta envoltorio de la lista. Recibe el nombre del ATRIBUTO Java, no de la etiqueta
