Semáforos en Java

Resumen de los apuntes y resolución de las 14 actividades usando solo lo que se ve en el tema (Semaphore, acquire, release, mutex y colas de espera).

Resumen API Patrones Consejos Ejercicios 1–14

1. Qué es un semáforo

  • Inventado por Dijkstra (finales de los 60). Primer mecanismo que sincroniza sin espera activa: el hilo se bloquea y no consume CPU.
  • Es un contador entero + dos operaciones atómicas: adquirir (acquire) y liberar (release).
  • Valor 0 = semáforo en rojo (cerrado). Valor >0 = en verde; el número indica cuántos hilos pueden pasar.
  • Binario: valores 0–1 (se usa como mutex). General: valores 0..N.
OperaciónEfecto sobre el contadorSi el contador es 0…
acquire()Resta 1El hilo se bloquea hasta que otro haga release()
release()Suma 1 (despierta a un hilo bloqueado si lo hay)Nunca bloquea
El contador nunca baja de 0, pero sí puede subir por encima del valor inicial: new Semaphore(0) + release(10) → 10 permisos.

2. La clase java.util.concurrent.Semaphore

Constructores

ConstructorQué hace
Semaphore(int permits)Crea el semáforo con N permisos. No justo por defecto (más eficiente).
Semaphore(int permits, boolean fair)fair = true → los hilos se despiertan en orden de llegada (cola FIFO). false → orden aleatorio.

Métodos

MétodoQué hace
acquire()Coge 1 permiso; se bloquea si no hay. Lanza InterruptedException.
acquire(int n)Coge n permisos de golpe; se bloquea hasta que haya n.
release() / release(int n)Devuelve 1 o n permisos.
tryAcquire()Intenta coger 1 permiso sin bloquear: true si lo consigue, false si no.
availablePermits()Permisos disponibles ahora mismo.
getQueueLength()Estimación de hilos esperando.
reducePermits(int n)Reduce los permisos disponibles.
toString()Identificador + estado del semáforo.

3. Los 4 usos que aparecen en el tema

① Sincronizar / ordenar (permisos = 0) El que debe ir después hace acquire() y se bloquea; el que va primero hace release() al terminar. Ej. 1: BUENAS → TARDES. 
Semaphore turno = new Semaphore(0);
// Hilo B:  turno.acquire(); ...
// Hilo A:  ...; turno.release();
② Limitar hilos en la región crítica (permisos = N) Como máximo N hilos dentro a la vez. Ej. 2: parking de 2 plazas. 
Semaphore sem = new Semaphore(5);
sem.acquire();
// región crítica
sem.release();
③ Mutex (permisos = 1) Exclusión mutua para tocar variables compartidas (sustituye a synchronized). 
Semaphore mutex = new Semaphore(1);
mutex.acquire();
contador++;
mutex.release();
④ Productor‑Consumidor (3 semáforos) lleno = huecos libres (N), vacio = elementos (0), mutex = acceso a la cola (1). 
// Productor        // Consumidor
lleno.acquire();    vacio.acquire();
mutex.acquire();    mutex.acquire();
cola.offer(x);      x = cola.poll();
mutex.release();    mutex.release();
vacio.release();    lleno.release();

Patrón extra: esperar a que se cumpla una condición

Lo necesitan los ejercicios 8, 9, 11 y 12. Es la aplicación directa de los consejos del tema: un semáforo sin permisos por cada condición de bloqueo, abrir el mutex antes de bloquearse y llamar a release() tantas veces como hilos esperan (no hay notifyAll()).

int esperando = 0;                       // cuántos hilos hay bloqueados en 'cola'
Semaphore mutex = new Semaphore(1);
Semaphore cola  = new Semaphore(0);      // aquí se duermen los que no pueden pasar

// ---- entrar ----
mutex.acquire();
while (!condicion) {                    // while, no if: al despertar se vuelve a comprobar
    esperando++;
    mutex.release();                       // ¡soltar el mutex ANTES de dormir! (evita interbloqueo)
    cola.acquire();
    mutex.acquire();
}
/* modificar estado */
mutex.release();

// ---- salir / cambiar estado ----
mutex.acquire();
/* modificar estado */
cola.release(esperando);                   // "notifyAll" casero
esperando = 0;
mutex.release();

4. Consejos del tema

  • Los semáforos binarios de exclusión mutua se llaman mutex.
  • Usa un semáforo sin permisos para bloquear hilos que esperan una condición (el equivalente al wait()). Uno por cada condición.
  • Libera el mutex siempre que puedas antes de bloquearte o de abrir/cerrar otro semáforo → evita interbloqueos.
  • No hay notifyAll(): llama a release() tantas veces como acquire() pendientes haya.
  • Orden en productor/consumidor: primero el semáforo de condición, luego el mutex. Al revés puedes bloquearte con el mutex cogido.
  • Queue: usar offer() y poll() (devuelven false/null en vez de lanzar excepción).

1TIC‑TAC intercaladoPatrón ① · 3 clases

Dos Runnable (hiloTIC, hiloTAC) que imprimen sin parar; la salida debe ser TIC‑TAC‑TIC‑TAC…, empezando por TIC.

Idea: dos semáforos que se pasan el turno. semTic empieza con 1 (TIC arranca) y semTac con 0.

HiloTIC.java
package ejercicio1;

import java.util.concurrent.Semaphore;

public class HiloTIC implements Runnable {
    Semaphore semTic, semTac;

    public HiloTIC(Semaphore semTic, Semaphore semTac) {
        this.semTic = semTic;
        this.semTac = semTac;
    }

    @Override
    public void run() {
        while (true) {
            try {
                semTic.acquire();      // espero mi turno
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
            System.out.print("TIC-");
            semTac.release();          // le doy el turno a TAC
        }
    }
}

    @Override

        System.out.println("Arranca el coche número " + numcoche);

Parking.java
package ejercicio3;

import java.util.concurrent.Semaphore;

public class Parking {
    static final int CAPACIDAD = 2;
    private Semaphore semaforo = new Semaphore(CAPACIDAD, true);  // plazas (FIFO)
    private Semaphore mutex = new Semaphore(1);                   // protege el array
    private boolean[] plazas = new boolean[CAPACIDAD];            // false = libre

    private int libres() {
        int n = 0;
        for (boolean p : plazas) {
            if (!p) n++;
        }
        return n;
    }

    public int entrarParking(Coche coche) throws InterruptedException {
        semaforo.acquire();            // espero a que haya plaza
        mutex.acquire();
        int plaza = 0;
        while (plazas[plaza]) plaza++; // primera libre (seguro que hay una)
        plazas[plaza] = true;
        System.out.println("=>El coche número " + coche.getNumcoche() + " entra al Parking");
        System.out.println("---------Coche número " + coche.getNumcoche()
                + " ha aparcado en la plaza " + plaza + ". Quedan libres " + libres());
        mutex.release();
        return plaza;
    }

    public void salirParking(Coche coche, int plaza) throws InterruptedException {
        mutex.acquire();
        plazas[plaza] = false;
        System.out.println("<= Coche número " + coche.getNumcoche()
                + " abandona el parking. Quedan libres " + libres());
        mutex.release();
        semaforo.release();            // dejo pasar al siguiente
    }
}

public class Principal {
    public static void main(String[] args) {
        Parking parking = new Parking();
        for (int i = 1; i <= 4; i++) {
            new Thread(new Coche(parking, i)).start();
        }
    }
}

43 amigos y 1000 globos (sin synchronized)Patrón ③ · 2 clases

Variable compartida explotados; el total debe ser exactamente 1000. Al final, cuántos ha explotado cada uno.

Idea: mutex para la comprobación y el incremento juntos (si comprobaras fuera del mutex, dos amigos podrían pasar del 1000).

Amigo.java
package ejercicio4;

import java.util.concurrent.Semaphore;

public class Amigo extends Thread {
    static int explotados = 0;                       // variable compartida
    static Semaphore mutex = new Semaphore(1, true); // justo: se reparten los globos
    int misGlobos = 0;

    public Amigo(String nombre) {
        super(nombre);
    }

    @Override
    public void run() {
        while (true) {
            try {
                mutex.acquire();
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
            if (explotados >= 1000) {
                mutex.release();                     // ¡soltar antes de salir!
                break;
            }
            explotados++;
            misGlobos++;
            mutex.release();
            try {
                sleep(1);                            // tiempo en explotar el globo
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }
    }
}
Principal.java
package ejercicio4;

public class Principal {
    public static void main(String[] args) throws InterruptedException {
        Amigo[] amigos = { new Amigo("Ana"), new Amigo("Luis"), new Amigo("Eva") };

        for (Amigo a : amigos) a.start();
        for (Amigo a : amigos) a.join();             // esperar a que acaben

        for (Amigo a : amigos) {
            System.out.println(a.getName() + " ha explotado " + a.misGlobos + " globos");
        }
        System.out.println("Total: " + Amigo.explotados);   // 1000
    }
}

7Productor‑Consumidor con ficheroPatrón ④ · 4 clases

Igual que el ejemplo 3, pero el buffer es un fichero de texto: el productor escribe una cadena y el consumidor la lee de ahí.

Idea: los semáforos (lleno=5, vacio=0, mutex=1) y el orden de acquire/release se quedan igual. Solo cambia Buffer: el fichero hace de cola (se escribe al final, se lee la primera línea).

Buffer.java
package ejercicio7;

import java.io.*;
import java.util.ArrayList;
import java.util.List;

public class Buffer {
    static final String FICHERO = "buffer.txt";

    // encolar: añadir una línea al final (append = true)
    public static void escribir(String dato) throws IOException {
        try (PrintWriter pw = new PrintWriter(new FileWriter(FICHERO, true))) {
            pw.println(dato);
        }
    }

    // desencolar: leer la primera línea y reescribir el resto
    public static String leer() throws IOException {
        List<String> lineas = new ArrayList<>();
        try (BufferedReader br = new BufferedReader(new FileReader(FICHERO))) {
            String l;
            while ((l = br.readLine()) != null) lineas.add(l);
        }
        String primera = lineas.remove(0);
        try (PrintWriter pw = new PrintWriter(new FileWriter(FICHERO, false))) {
            for (String l : lineas) pw.println(l);
        }
        return primera;
    }

    // vaciar el fichero al empezar
    public static void vaciar() throws IOException {
        new FileWriter(FICHERO, false).close();
    }
}
Productor.java
package ejercicio7;

import java.io.IOException;
import java.util.concurrent.Semaphore;

public class Productor extends Thread {
    String name;
    Semaphore vacio, lleno, mutex;

    public Productor(String name, Semaphore vacio, Semaphore lleno, Semaphore mutex) {
        this.name = name;
        this.vacio = vacio;
        this.lleno = lleno;
        this.mutex = mutex;

            try {
                lleno.acquire();       // ¿hay hueco?

                System.out.println("Productor " + name + " escribe " + produce);
                mutex.release();
                vacio.release();       // aviso: hay un elemento más
            } catch (InterruptedException | IOException e) {
                e.printStackTrace();
            }
        }
    }
}

8Baño público y limpiadorTorniquete + condición · 4 clases

Capacidad ilimitada. El limpiador pone el letrero (nadie más entra), espera a que salgan todos, limpia y quita el letrero.

ElementoInicialUso
letrero1"Puerta". La persona hace acquire()+release() (pasa y la deja abierta). El limpiador hace acquire() y la deja cerrada mientras limpia.
mutex1Proteger dentro y limpiadorEsperando.
vacio0El limpiador se duerme aquí hasta que el último en salir le avise.
Banio.java
package ejercicio8;

import java.util.concurrent.Semaphore;

public class Banio {
    private Semaphore letrero = new Semaphore(1, true);
    private Semaphore mutex = new Semaphore(1);
    private Semaphore vacio = new Semaphore(0);
    private int dentro = 0;
    private boolean limpiadorEsperando = false;

    public void usarBanio(String nombre) throws InterruptedException {
        System.out.println(nombre + " quiere entrar en el baño");
        letrero.acquire();             // si hay letrero, me quedo aquí esperando
        letrero.release();             // paso y dejo la puerta libre al siguiente

        mutex.acquire();
        dentro++;
        System.out.println("\t" + nombre + " está utilizando el baño");
        mutex.release();

        Thread.sleep((long) (Math.random() * 1000));   // hacer lo habitual

        mutex.acquire();
        dentro--;
        System.out.println("\t\t=>" + nombre + " abandona el baño");
        if (dentro == 0 && limpiadorEsperando) {
            System.out.println("\t\t=>" + nombre + " es el último, avisa al limpiador");
            vacio.release();
        }
        mutex.release();
    }

    public void limpiarBanio() throws InterruptedException {
        letrero.acquire();             // poner letrero: ya no entra nadie
        System.out.println("--El limpiador pone el cartel para limpiar el baño");

        mutex.acquire();
        if (dentro > 0) {
            limpiadorEsperando = true;
            mutex.release();           // soltar mutex antes de dormir
            vacio.acquire();           // esperar a que se vacíe
            mutex.acquire();
            limpiadorEsperando = false;
        }
        mutex.release();

        System.out.println("XX Limpiando baño");
        Thread.sleep(2000);
        System.out.println("XX Baño limpio");
        letrero.release();             // quitar letrero
    }
}

9Sala de baile equilibradaPatrón condición · 3 clases

Si al entrar hay más personas de tu sexo que del contrario, esperas hasta que se equilibre.

Condición para entrar: un hombre entra si hombres <= mujeres; una mujer si mujeres <= hombres. Un semáforo de espera por cada condición (colaH, colaM). Cada vez que alguien entra o sale se despierta a los que esperan para que lo vuelvan a comprobar.

SalaBaile.java
package ejercicio9;

import java.util.concurrent.Semaphore;

public class SalaBaile {
    private int hombres = 0, mujeres = 0;
    private int espH = 0, espM = 0;                  // cuántos esperan de cada sexo
    private Semaphore mutex = new Semaphore(1);
    private Semaphore colaH = new Semaphore(0);
    private Semaphore colaM = new Semaphore(0);

    // despierta a todos los que esperan (llamar con el mutex cogido)
    private void avisar() {
        colaH.release(espH);
        espH = 0;
        colaM.release(espM);
        espM = 0;
    }

    private String estado() {
        return " [H=" + hombres + " M=" + mujeres + "]";
    }

    public void entraHombre(String n) throws InterruptedException {
        mutex.acquire();
        while (hombres > mujeres) {
            System.out.println("  " + n + " espera" + estado());
            espH++;
            mutex.release();
            colaH.acquire();
            mutex.acquire();
        }
        hombres++;
        System.out.println("=> " + n + " entra" + estado());
        avisar();
        mutex.release();
    }

    public void saleHombre(String n) throws InterruptedException {
        mutex.acquire();
        hombres--;
        System.out.println("<= " + n + " sale" + estado());
        avisar();
        mutex.release();
    }

    public void entraMujer(String n) throws InterruptedException {
        mutex.acquire();
        while (mujeres > hombres) {
            System.out.println("  " + n + " espera" + estado());
            espM++;
            mutex.release();
            colaM.acquire();
            mutex.acquire();
        }
        mujeres++;
        System.out.println("=> " + n + " entra" + estado());
        avisar();
        mutex.release();
    }

    public void saleMujer(String n) throws InterruptedException {
        mutex.acquire();
        mujeres--;
        System.out.println("<= " + n + " sale" + estado());
        avisar();
        mutex.release();
    }
}

10Canarios y encargado que reponePatrón ② + acquire(n) · 4 clases

10 canarios, comedero de 3. El encargado repone cada 10 ms: espera a que no haya nadie comiendo y, mientras repone, nadie entra.

Idea: el encargado pide los 3 permisos a la vez con acquire(3). Solo los consigue con el comedero vacío, y mientras los tiene nadie entra. Con fair = true, los canarios que lleguen después de él no lo adelantan.

Comedero.java
package ejercicio10;

import java.util.concurrent.Semaphore;

public class Comedero {
    static final int HUECOS = 3;
    private Semaphore huecos = new Semaphore(HUECOS, true);   // justo (FIFO)

    public void comer(String n) throws InterruptedException {
        huecos.acquire();
        System.out.println(n + " come. Huecos libres: " + huecos.availablePermits());
        Thread.sleep(10);
        System.out.println(n + " deja de comer");
        huecos.release();
    }

    public void reponer() throws InterruptedException {
        System.out.println("** Encargado quiere reponer");
        huecos.acquire(HUECOS);        // espera a que salgan todos y bloquea la entrada
        System.out.println("** Encargado reponiendo alpiste...");
        Thread.sleep(10);
        System.out.println("** Encargado termina de reponer");
        huecos.release(HUECOS);
    }
}

11Depósito de agua de 200 LPatrón condición · 4 clases

mete_agua(L) espera si no cabe; saca_agua(L) espera si no hay suficiente.

Idea: dos condiciones → dos semáforos de espera (colaMeter, colaSacar). Al meter agua se despierta a los que querían sacar, y al sacar, a los que querían meter.

Deposito.java
package ejercicio11;

import java.util.concurrent.Semaphore;

public class Deposito {
    static final int CAPACIDAD = 200;
    private int litros = 0;
    private int espMeter = 0, espSacar = 0;
    private Semaphore mutex = new Semaphore(1);
    private Semaphore colaMeter = new Semaphore(0);
    private Semaphore colaSacar = new Semaphore(0);

    public void meteAgua(String n, int L) throws InterruptedException {
        mutex.acquire();
        while (litros + L > CAPACIDAD) {
            System.out.println("  " + n + " quiere meter " + L + "L pero no cabe (" + litros + "L)");
            espMeter++;
            mutex.release();
            colaMeter.acquire();
            mutex.acquire();
        }
        litros += L;
        System.out.println("+ " + n + " mete " + L + "L -> " + litros + "L");
        colaSacar.release(espSacar);   // ahora hay más agua: que lo reintenten
        espSacar = 0;
        mutex.release();
    }

    public void sacaAgua(String n, int L) throws InterruptedException {
        mutex.acquire();
        while (litros < L) {
            System.out.println("  " + n + " quiere sacar " + L + "L pero solo hay " + litros + "L");
            espSacar++;
            mutex.release();
            colaSacar.acquire();
            mutex.acquire();
        }
        litros -= L;
        System.out.println("- " + n + " saca " + L + "L -> " + litros + "L");
        colaMeter.release(espMeter);   // ahora hay más hueco
        espMeter = 0;
        mutex.release();
    }
}

12Ascensor (6 personas / 450 kg)Patrón condición · 3 clases

sube_persona(nombre, peso) bloquea si está lleno o si el peso se pasa; baja_persona actualiza y despierta a quien pueda subir.

Condición para subir: personas < 6 && kilos + peso <= 450. Al bajar alguien se despierta a todos los que esperan (un ligero puede caber aunque uno pesado no).

Ascensor.java
package ejercicio12;

import java.util.concurrent.Semaphore;

public class Ascensor {
    static final int MAX_PERSONAS = 6;
    static final float MAX_KG = 450;
    private int personas = 0, esperando = 0;
    private float kilos = 0;
    private Semaphore mutex = new Semaphore(1);
    private Semaphore cola = new Semaphore(0);

    public void subePersona(String nombre, float peso) throws InterruptedException {
        mutex.acquire();
        while (personas == MAX_PERSONAS || kilos + peso > MAX_KG) {
            System.out.println("  " + nombre + " (" + peso + "kg) espera. Dentro: "
                    + personas + " / " + kilos + "kg");
            esperando++;
            mutex.release();
            cola.acquire();
            mutex.acquire();
        }
        personas++;
        kilos += peso;
        System.out.println("↑ " + nombre + " sube. Dentro: " + personas + " / " + kilos + "kg");
        mutex.release();
    }

    public void bajaPersona(String nombre, float peso) throws InterruptedException {
        mutex.acquire();
        personas--;
        kilos -= peso;
        System.out.println("↓ " + nombre + " baja. Dentro: " + personas + " / " + kilos + "kg");
        cola.release(esperando);       // todos reintentan
        esperando = 0;
        mutex.release();
    }
}

13Cancha de pádel (grupos de 4)Patrón ② + barrera · 3 clases

Los jugadores ocupan puesto hasta ser 4; con el cuarto se juega (10 s). Los que llegan durante el partido esperan. El último en salir avisa a los que esperan.

SemáforoInicialUso
cancha4Puestos. No se devuelve al salir uno a uno: solo el último devuelve los 4 → nadie entra a mitad de partido.
empezar0Barrera: los 3 primeros esperan aquí; el 4º hace release(3).
mutex1Proteger enCancha.
Cancha.java
package ejercicio13;

import java.util.concurrent.Semaphore;

public class Cancha {
    private Semaphore cancha = new Semaphore(4, true);
    private Semaphore empezar = new Semaphore(0);
    private Semaphore mutex = new Semaphore(1);
    private int enCancha = 0;

    public void jugar(String n) throws InterruptedException {
        cancha.acquire();              // ocupo un puesto (o espero)
        mutex.acquire();
        enCancha++;
        System.out.println(n + " ocupa puesto. Jugadores: " + enCancha + "/4");
        if (enCancha < 4) {
            mutex.release();
            empezar.acquire();         // espero al cuarto
        } else {
            System.out.println("### Empieza el partido ###");
            empezar.release(3);        // despierto a los otros 3
            mutex.release();
        }

        Thread.sleep(10000);           // partido

        mutex.acquire();
        enCancha--;
        System.out.println(n + " abandona la cancha");
        if (enCancha == 0) {
            System.out.println(n + " es el último: avisa a los que esperan");
            cancha.release(4);         // cancha libre para 4 nuevos
        }
        mutex.release();
    }
}

14Cinta de plátanos (calidad A / B)Patrón ④ con turnos · 4 clases

Productores ponen manojos A o B en una cinta ilimitada. El señor A recoge solo A y el señor B solo B, siempre en orden: solo se recoge el primero de la cinta.

Idea: cinta = Queue<Character> con mutex. Un semáforo por consumidor (turnoA, turnoB, a 0). Regla: si la cinta no está vacía, hay exactamente un permiso dado al consumidor de la calidad del primer manojo. Cinta ilimitada → no hace falta semáforo lleno.

Cinta.java
package ejercicio14;

import java.util.LinkedList;
import java.util.Queue;
import java.util.concurrent.Semaphore;

public class Cinta {
    private Queue<Character> cinta = new LinkedList<>();
    private Semaphore mutex = new Semaphore(1);
    private Semaphore turnoA = new Semaphore(0);
    private Semaphore turnoB = new Semaphore(0);

    private void avisar(char calidad) {
        if (calidad == 'A') turnoA.release();
        else turnoB.release();
    }

    public void poner(String productor, char calidad) throws InterruptedException {
        mutex.acquire();
        cinta.offer(calidad);
        System.out.println(productor + " pone un manojo " + calidad + "   Cinta: " + cinta);
        if (cinta.size() == 1) avisar(calidad);      // es el primero de la cinta
        mutex.release();
    }

    public void recoger(char miCalidad) throws InterruptedException {
        Semaphore miTurno = (miCalidad == 'A') ? turnoA : turnoB;
        miTurno.acquire();             // espero a que el primero sea de mi calidad
        mutex.acquire();
        cinta.poll();
        System.out.println("\tSeñor " + miCalidad + " recoge un manojo " + miCalidad + "   Cinta: " + cinta);
        if (!cinta.isEmpty()) avisar(cinta.peek());  // aviso al dueño del nuevo primero
        mutex.release();
    }
}
